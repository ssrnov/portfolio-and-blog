Engineering Philosophy & Approach

I specialize in software engineering across modern web systems and distributed backend pipelines. Rather than reaching for heavy external dependencies by default, my methodology is rooted in mastering native platform APIs, clear modular decomposition, and writing predictable, debuggable code.

Throughout my academic studies and competitive engineering labs, I have focused on the delicate balance between developer velocity and long-term system maintainability. I prioritize low memory footprints, sub-second build times, and high accessibility standards (WCAG AAA).

Currently participating in TechSpace Folioryn '26, developing robust web applications with zero unnecessary runtime overhead and strict architecture constraints.

Core Principles

  • Standards Over Ephemeral Hype: Leverage stable browser and OS primitives before adding external dependencies.
  • Measurable Performance: Optimize for cold-start latency, memory efficiency, and deterministic data flow.
  • Accessibility by Default: Ensure complete keyboard navigation, semantic markup, and sufficient contrast across all screens.
